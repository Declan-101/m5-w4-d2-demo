JavaScript split()

Module 5 · Week 4 · Day 2 · Group Challenge

1. Split a string into characters

const characters = 'abcde'.split('');
An empty separator splits these five ASCII characters into separate array elements.


2. Split a paragraph using a regular expression
const paragraph = 'Spring Break! Are you ready? Will be out of town. Looking forward to spending time on the beach.';
const sentences = paragraph.split(/[!?.]/).filter(part => part !== '');
/[!?.]/ matches an exclamation mark, question mark, or period. A period inside this character class is literal. The final period leaves an empty element, which filter removes. Leading spaces stay intact to match the requested output.


Time complexity
For these fixed, single-character separators, splitting scans the input in O(n) time. Filtering also takes O(n), so the combined time remains O(n). The returned strings and array require O(n) output space.
